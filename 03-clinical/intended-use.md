# Intended-Use Classification

Each feature dossier records: intended user, patient population, clinical context, intended purpose, input data, output, automation level, actionability, time criticality, failure consequence, claims in marketing copy, jurisdictions and regulatory owner.

A feature cannot move to implementation until it is classified into one of: non-clinical SaaS, administrative healthcare software, patient engagement, clinical workflow support, clinical decision support, or candidate regulated medical-device function.
