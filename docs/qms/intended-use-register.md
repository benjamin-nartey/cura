# Intended-use register — foundation slice

Owner: foundation implementation. Jurisdiction review: not done. Do not deploy this slice for real care.

| Feature | Intended user | Intended use class | Purpose | Automation | Non-goals |
| --- | --- | --- | --- | --- | --- |
| Development directory | Engineer running the local app | Non-clinical SaaS | Pick a seeded workforce identity so the server can derive tenant, facility, role, and purpose of use | None | Production authentication, MFA, SSO |
| Facility chart | Clinician or nurse at one facility | Clinical workflow support | Read and append the local source record | None | Diagnosis, treatment, ordering outside the record |
| Patient registration | Clinician | Clinical workflow support | Create a patient row scoped to the session facility | MRN allocated by the server | Cross-facility registration |
| Threshold label | Clinician or nurse reading a result | Clinical workflow support | Show whether a number is outside a configured bound | Deterministic comparison | Alerts, paging, recommendations, device claims |
| Timeline and since-last-visit | Clinician or nurse | Clinical workflow support | Reconstruct recorded events, filter them by source kind, and list what was stored after the last finished encounter | Deterministic projection | Summaries that add facts, a stored second timeline, clinical copilot |
| Patient state | Clinician or nurse | Clinical workflow support | Rebuild a versioned snapshot of active problems, medications, allergies, latest results, conflicts, and pending work | Deterministic rebuild from source rows | Risk scores, diagnosis, treatment advice, silent merges, automatic replacement of the chart |
| Evidence citations | Clinician or nurse | Clinical workflow support | File each derived line with a source citation and mark the line invalidated when that source changes | Deterministic hash of the source row | Model-written claims, claims with no citation, treatment advice |
| Model gateway | Clinician, nurse, or auditor | Non-clinical SaaS | Record a traced attempt and refuse generation while no model is allowlisted | None. The gate does not call a provider | Clinical drafts, diagnosis, treatment text, direct provider calls |
| Agent runtime | Clinician or nurse | Clinical workflow support | Run a versioned chart-review manifest, list source identifiers, and wait for a second person at the facility | Durable steps. No model. Draft tools do not write | Diagnosis, treatment text, unapproved chart changes, direct provider calls |
| Clinical copilot | Clinician or nurse | Clinical workflow support | Show a patient summary and answer a question only with supported, cited claims | Retrieval of stored claims. Grounding threshold is 1 | Diagnosis, treatment advice, model-written sentences, answers that cite a changed source |
| Documentation draft | Clinician or nurse | Clinical workflow support | Record consent, quote clinician-typed text into a draft, and accept or reject it without signing | None. Audio is not transcribed | Speech-to-text, speaker labels, automatic signature, orders, chart writes from a draft |
| Lab order and critical flag | Clinician or nurse at one facility | Clinical workflow support | Place a catalog order, record a specimen and result, and show a critical flag from a local numeric pin | Deterministic comparison. The gateway refuses an explanation | Diagnosis, treatment, an analyzer, AI-cleared alerts, a generated trend narrative |
| Medication safety check | Clinician or nurse at one facility | Clinical workflow support | Propose a formulary item, show allergy, interaction, duplicate, and formulary warnings from a local pin, and record dispense and administration counts | Deterministic rules. The gateway refuses an explanation | Diagnosis, dose advice, a drug-knowledge vendor, AI-cleared warnings |
| Care coordination | Clinician or nurse at one facility | Clinical workflow support | Record a referral, a follow-up task, a clinician-typed care plan, and a template message when consent allows it | Templates are stored. Failed outreach opens a task. The gateway refuses an explanation | SMS, email, chart copying, diagnosis, model-written messages |
| Patient record | The person whose row is linked to the patient principal | Clinical workflow support | Show that person's appointments, medications, allergies, and results, and store a question, message, coverage note, recorded amount, or visit request | Pinned sentences. Urgent phrases use a fixed emergency instruction. The gateway refuses generation | Diagnosis, treatment advice, charges, outbound delivery, the clinician chart, model-written explanations |
| Facility twin | Clinician or nurse at one facility | Clinical workflow support | Show counts of stored appointments, open encounters, lab backlog, pharmacy backlog, beds, shifts, and equipment, with a freshness mark | Deterministic counts. The gateway refuses an explanation | A bed-management feed, a forecast, diagnosis, model-written capacity |
| Operations comparisons | Clinician or nurse at one facility | Clinical workflow support | Show wait age, stored-bed capacity, a recorded on-hand count, a staffing comparison, and the largest stored backlog, each with factors and confidence | Deterministic comparison. A hold leaves the sentence. The gateway refuses an explanation | A forecast, a staffing order, an inventory prediction, diagnosis, model-written recommendations |
| Analytics mart | Auditor in one organization | Administrative healthcare software | Copy outbox events into a separate mart and export pinned counts after de-identification and a small-cell check | Deterministic ingest and counts. No model | A patient list, SQL against the chart, Kafka, Iceberg, diagnosis |
| Population counts | Auditor in one organization | Administrative healthcare software | Count stored chronic problems and systolic results when the group is at least 5 and the jurisdiction tag allows it | Deterministic counts. Groups below 5 are omitted. No model | A case list, outbreak detection, a vaccine registry, a map, diagnosis |
| Research workspace | Auditor in one organization | Administrative healthcare software | Freeze a population count snapshot and release an export only after a different auditor decides | Immutable versions. Ethics status stays not-reviewed. No model | An ethics approval, a notebook runtime, a patient-level extract, diagnosis |
| Imaging metadata | Clinician or nurse at one facility | Clinical workflow support | Store a modality, accession, date, and short description, link one typed report, and release modality and date only | The gateway refuses interpretation. Payloads over 1024 characters are refused | A PACS, pixel storage, a viewer, diagnostic imaging AI |
| Device readings | Clinician or nurse at one facility | Clinical workflow support | Register a pinned device kind and store a typed reading in the facility catalog unit, with at most 3 open threshold marks | Duplicate and older times do not open another mark. The gateway refuses an explanation. No page | A wearable stream, connectivity other than not-connected, paging, a chart observation |
| Revenue ledger | Organization admin | Administrative healthcare software | Record invoice and payment cents, leave eligibility unchecked, and keep a claim as a draft | Sums reconcile. The gateway cannot change a cent. No model | A payer check, a submitted claim, a denial, a collected payment, a subscription charge |
| Evaluation hold | Auditor in one organization | Administrative healthcare software | Store the pinned refusal cases, run them through the gateway, and keep a signed hold | Reproducible from the pin. Promotion stays not-promoted. No model score | A promoted clinical model, a subgroup metric, a drift score |
| Enterprise residency | Organization admin | Non-clinical SaaS | Pin this organization to the local database file and record that failover was not run | The only region name is local-sqlite. No model | SSO, SCIM, a customer key, a second region, a tenant move |
| Marketplace listing | Organization admin and auditor | Non-clinical SaaS | Store an administrative listing, a hold review, a not-billed share, and a stop | Scope stays health.read. No model | An installed extension, an OAuth secret, a sandbox tenant, a revenue share |
| Release train | Auditor in one organization | Non-clinical SaaS | Store a not-approved strategy, local gates, and a not-released attempt | The gateway must refuse. No model update | A regulatory approval, a clinical benefit result, a signed risk file, a performance rate |
| Module cards | Auditor in one organization | Non-clinical SaaS | Store each catalog module with its own intended use and model card | The gateway must refuse that module. No score | A dataset, a workflow result, a subgroup metric, a blanket approval |
| Audit review | Auditor in the same organization | Administrative healthcare software | Read access decisions for the organization | None | Changing the chart, bulk export |
| Facility terminology catalog | Clinician or nurse recording a result | Clinical workflow support | Accept only codes pinned for that facility and store the code-system version on the source row | Lookup against a local pin | Full SNOMED, LOINC, or ICD distribution. Diagnosis. Automatic mapping changes to old rows |
| FHIR R4 projection | Clinician or nurse at one facility, or a local client using that session | Clinical workflow support | Read the facility chart as R4 JSON and append a final observation through the facility catalog | Deterministic mapping | SMART on FHIR, R5 responses, outbound webhooks, diagnosis, a second clinical record |

Marketing claims allowed for this slice: none that mention detection, prediction, or treatment.
