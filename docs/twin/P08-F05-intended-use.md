# P08-F05 intended use

Authorized care-team users inspect source-backed synthetic patient assertions, pending coordination and exact before/after evidence in the local simulation. This is read-only derived inspection, not diagnosis, treatment guidance, medication reconciliation, clinical prioritization or production clinical readiness. Risk class C is a conservative engineering assessment pending qualified review.

Counts describe recorded source assertions within currently authorized coverage. Unknown allergy assessments remain unknown. Draft medications do not establish current therapy. Unprioritized observations remain visible without inventing clinical recency. Missing/no-prior-visit/zero counts never establish normality or safety. Pending coordination uses its real source record and ownership/status. Conflicts remain side by side under Source tools; requests are source-verification requests, not clinical resolution.

Source and live identity gates apply equally to desktop and native adapters. Synthetic scenario data is linked to the existing Kofi Mensah local fixture, never real patient data. Existing prerequisite, clinical, privacy, architecture and licensing reviews remain pending, reviewer identity null, production clinical functionality disabled. Engineering evidence does not constitute formal acceptance.
