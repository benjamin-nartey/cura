# P07-F04 risk controls

Conservative risk C: clinical facts are displayed without new interpretation or execution. Qualified clinical/privacy/architecture/licensing review remains pending.

- Wrong/stale facts: exact patient/version/ledger/hash matching, existing server authorization, synchronous epoch visibility gates, explicit historical badges, source-watch invalidation and manual refresh.
- Missing facts mistaken as reassurance: unknown times/provenance explicit; empty, denied, stale and offline are distinct. No generated clinical facts.
- Offline or late response leakage: abort on context changes, epoch guards, no persistent clinical cache, no queued/replayed commands; modal redaction on uncertainty.
- Keyboard exclusion: native dialog, explicit forward/reverse Tab wrapping, Escape, focus restoration, roving event/date navigation, responsive layout and reduced-motion support.
- Operational overclaim: loaded/check times explicitly operational, polling bounded/throttled, no live-feed guarantee. Materialization current status remains API-backed.
- Regression/data loss: full domain and focused tests, live web/mobile regressions, original-row preservation and existing evidence retained. No clinical cleanup deletes or source migration.
