# Threat Model Baseline

Threat categories include account takeover, insider misuse, cross-tenant leakage, IDOR, API abuse, ransomware/data destruction, supply-chain compromise, malicious documents, prompt injection, indirect prompt injection, tool abuse, training-data poisoning, model exfiltration, PHI disclosure, unsafe automation and compromised medical-device integrations.

Every RFC has a data-flow diagram, trust boundaries, assets, threats, mitigations, residual risk and test cases.

The local foundation slice records its trust boundary, threats, and tests in `docs/rfc/RFC-0001-platform-foundation.md`. The FHIR projection adds its boundary and tests in `docs/rfc/RFC-0003-fhir-r4.md`. The timeline projection adds its boundary and tests in `docs/rfc/RFC-0004-clinical-timeline.md`. The patient-state build adds its boundary and tests in `docs/rfc/RFC-0005-patient-state.md`. Evidence citations add their boundary and tests in `docs/rfc/RFC-0006-evidence.md`. The model gateway adds its boundary and tests in `docs/rfc/RFC-0007-ai-gateway.md`. The agent runtime adds its boundary and tests in `docs/rfc/RFC-0008-agent-runtime.md`. The clinical copilot adds its boundary and tests in `docs/rfc/RFC-0009-clinical-copilot.md`. Documentation drafts add their boundary and tests in `docs/rfc/RFC-0010-clinical-documentation.md`. Laboratory orders and critical flags add their boundary and tests in `docs/rfc/RFC-0011-curalab.md`. Medication safety checks add their boundary and tests in `docs/rfc/RFC-0012-curarx.md`. Care coordination and outreach add their boundary and tests in `docs/rfc/RFC-0013-care-coordination.md`. The patient record adds its boundary and tests in `docs/rfc/RFC-0014-patient-record.md`. The facility projection adds its boundary and tests in `docs/rfc/RFC-0015-facility-twin.md`.
