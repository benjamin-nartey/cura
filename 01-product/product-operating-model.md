# Product Operating Model

Every feature must have: problem statement, persona, intended user, intended use, non-goals, workflow map, safety classification, privacy classification, success metric, SLO impact, cost budget, rollout plan and retirement plan.

## Product council gates
Discovery -> Intended-use classification -> PRD -> RFC -> Risk review -> Build -> Qualification -> Release -> Monitor -> Change control.

## Portfolio categories
- Core healthcare system of record
- Clinical decision support
- Patient engagement
- Operations intelligence
- Financial/claims intelligence
- Research/population health
- Regulated medical AI modules
- Platform/marketplace
